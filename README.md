# Finlogy Finance

A responsive browser-based finance calculator and financial-record starter built with HTML, CSS and JavaScript.

## Features in this starter

- Simple and compound interest calculators
- Loan EMI calculator
- ROI calculator
- Indicative forex conversion using an external exchange-rate endpoint
- Manual stock holding records
- Income and expense transactions
- PDF transaction-record receipts
- Calculation history
- CSV transaction export and JSON backup
- Responsive layout and dark mode

## Run locally

1. Clone or download this repository.
2. Open the folder in VS Code.
3. Run `index.html` using the Live Server extension, or serve the folder with any static HTTP server.
4. The application uses browser `localStorage` for this starter.

## GitHub Pages

Push these files to the repository root, then open **Settings → Pages** and configure deployment from the default branch and root folder.

## Important limitations

This is a front-end starter, not a production financial platform.

- Data is saved only in the current browser. Clearing browser storage can delete records.
- There is no authentication, cloud database, cross-device synchronization, or server-side backup.
- Stock prices are entered manually; live stock-market data is not included.
- Forex data depends on the availability and terms of an external public API. Rates may be delayed or indicative.
- PDF receipts are records generated by this app, not proof of payment or bank confirmations.
- Do not store sensitive financial information until a secure backend, authentication, authorization, and backups have been implemented.
